CHANGE OF PLANS / Split in plans?

Ok so there is a slight change of plans and I’m going to turn the project into kernel dev. Basically, I tried out LFS for a bit and followed the things and yeah I did learn a bit and I think I followed it almost all the way, but I just think that this isn’t actually all that beneficial and that a lot of the things I already learned when manually installing arch or gentoo or something.

And so I thought that hmmmmmmm, it would be way more beneficial for me, especially since I have an interest in pwn, that it would actually be better if I just tried to make my own kernel inside a VM or something.

So the plan for right now is to learn more C (because I already know the basics of C++) and maybe build a little project to solidify my understanding. And then, I’ll try to tackle some kernel modules first. There will DEFINITELY be more updates on it.

I think I’ll still follow through with the LFS build and so I’ll complete it pretty quickly and get a basic sway setup going. And then, I’ll continue to learn C and make that its seperate project and idea thing.

homework

So the homework now is just to complete the LFS pretty quickly and turn it into an iso and just quickly finish it so that I can focus on the bigger project. Also, for my little project to learn C, I’m making a local password manager completely in C!
